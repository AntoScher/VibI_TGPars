# Telegram Message Analyzer & Bot

Этот проект представляет собой комплексную систему для сбора, анализа и взаимодействия с сообщениями из ваших Telegram-чатов. Он состоит из трёх основных компонентов:

1.  **Сборщик сообщений (`main.py`)**: Подключается к вашему Telegram-аккаунту, собирает исторические и новые сообщения в реальном времени, сохраняя их в базу данных.
2.  **Телеграм-бот (`bot.py`)**: Предоставляет интерфейс для взаимодействия с собранными данными через команды в Telegram (например, для получения статистики или анализа).
3.  **Веб-интерфейс (`web_app`)**: Визуализирует собранные данные и статистику через веб-страницу.

Компоненты работают независимо и обмениваются данными через общую базу данных SQLite.

---

Этот проект состоит из трёх независимых программ, которые должны работать одновременно в разных терминалах.

## Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

## Шаг 2: Настройка конфигурации

Был создан файл `.env`. **Вам необходимо отредактировать его** и вписать свои реальные данные.

-   `TG_API_ID` и `TG_API_HASH`: Возьмите их на [my.telegram.org](https://my.telegram.org).
-   `BOT_TOKEN`: Получите у бота [@BotFather](https://t.me/BotFather) в Telegram.
-   `ALLOWED_USER_IDS`: Ваш ID в Telegram. Можете узнать его у бота [@userinfobot](https://t.me/userinfobot). Можно перечислить несколько ID через запятую.
-   `DEEPSEEK_API_KEY`: API-ключ от сервиса Deepseek для работы функции суммаризации чатов.
-   `TARGET_CHAT_IDS` (опционально): ID чатов, из которых нужно собирать сообщения. Перечислите через запятую. ID можно узнать из логов `main.py` при первом запуске. Если не указано, скрипт попытается собрать сообщения из первого диалога в вашем списке.
-   `HISTORY_FETCH_LIMIT` (опционально): Количество исторических сообщений для сбора из каждого чата. По умолчанию `100`.

## Шаг 3: Запуск проекта

**Откройте три отдельных окна терминала (консоли).** В каждом из них выполните одну из следующих команд.

---

### Терминал 1: Запуск сборщика сообщений

Эта программа будет собирать сообщения из ваших чатов. При первом запуске потребуется ввести номер телефона и код, который придёт в Telegram.

```bash
python main.py
```

---

### Терминал 2: Запуск Телеграм-бота

Эта программа запустит вашего бота, который будет отвечать на команды.

```bash
python bot.py
```

> **Примечание:** Ошибка при запуске `bot.py` почти всегда означает, что вы неверно указали `BOT_TOKEN` или ваш ID в `ALLOWED_USER_IDS` в файле `.env`.

---

### Терминал 3: Запуск Веб-интерфейса

Эта команда запустит веб-сервер, на котором вы сможете видеть статистику и сообщения.

```bash
uvicorn web_app:app --host 0.0.0.0 --port 8000
```

После запуска откройте в браузере адрес [http://127.0.0.1:8000](http://127.0.0.1:8000).

> **Примечание:** Если веб-сервер запускается и тут же выключается, это не ошибка в коде. Это значит, что вы запускаете его неправильно. Убедитесь, что команда выполняется в **отдельном, чистом** терминале.
